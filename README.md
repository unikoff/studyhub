# StudyHub Planner

Консольный список задач на Python. Planner умеет добавлять задачи с приоритетом, показывать список, находить задачу по id, отмечать её выполненной, искать по части названия и показывать статистику.

## Требования

- Python 3.12. Проект проверен на Python 3.12.10.
- Git для получения исходного кода.
- Сторонние Python-пакеты не требуются.

## Получение и запуск в Windows PowerShell

```powershell
git clone https://github.com/unikoff/studyhub.git
Set-Location studyhub
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m app.main
```

Последняя команда запускает модуль app.main из корня проекта через Python виртуального окружения; активировать окружение отдельно не нужно. Если Python установлен под другой командой, используйте её при создании окружения.

## Команды

- `add` — добавить задачу. Введите непустое название и приоритет от 1 до 5.
- `list` — показать задачи в текущем запуске.
- `find` — найти задачу по положительному целому id.
- `done` — отметить найденную задачу выполненной.
- `search` — найти задачи, название которых содержит введённый фрагмент.
- `stats` — показать общее число задач, число выполненных и оставшихся, а также процент выполнения.
- `exit` — завершить текущий запуск.

## Контрольный сценарий

В меню последовательно выберите `add` и добавьте две задачи с любыми непустыми названиями и приоритетами 1–5. Используйте id, показанные Planner: команда `list` покажет обе задачи, `find` найдёт выбранную, `done` отметит её выполненной, а `search` найдёт задачу по части названия. После этого `stats` для двух задач, одна из которых выполнена, покажет `Всего: 2`, `Выполнено: 1`, `Осталось: 1` и `Процент выполнения: 50.0%`. Команда `exit` завершит работу.

## Ограничения

Задачи сохраняются полным JSON-снимком в `data/tasks.json` после успешного добавления и первого завершения. Новый запуск восстанавливает id, название, приоритет и статус задач. Файл данных локальный и не входит в Git.
