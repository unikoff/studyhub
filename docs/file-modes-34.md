# Режимы открытия файла — занятие 34

Проверка выполнена на отдельном временном `studyhub/data/tasks.txt`. Она не подключает файловое хранение к Planner.

| Режим | Что делает | Наблюдение в опыте |
| --- | --- | --- |
| `r` | Читает существующий файл с начала; отсутствующий файл вызывает `FileNotFoundError`. | Заголовки прочитаны с `encoding="utf-8"`; после выхода из `with` файловый объект закрыт. |
| `w` | Создаёт файл или сразу очищает прежнее содержимое, затем записывает новое. | Повторный вызов оставил только новый снимок, без старых строк. |
| `a` | Создаёт файл при необходимости и дописывает в конец. | Добавленная строка появилась после прежнего содержимого. Для полного снимка задач такой режим дал бы накопление старых данных. |

Временный пример использовал `save_titles()` с `w` для полного снимка и `load_titles()` с `r` для чтения. Эти функции не добавлены в `app` и не являются возможностью Planner в рамках этого исследовательского занятия.

Запись и чтение русских заголовков с одинаковым UTF-8 сохранили текст без изменений. `with` закрыл файл после завершения блока; это управляет временем жизни ресурса, но не гарантирует атомарность или восстановление старого содержимого.
