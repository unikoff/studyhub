# Архитектура StudyHub Planner

## Путь команды и данных

```text
Пользователь
    ↓ ввод / сообщения
CLI: run → execute_command → обработчик
    ↓ PlannerService
SQL-репозиторий → SQLAlchemy Session → SQLite
    ↓
Task: правила одной задачи

FastAPI request → dependency → отдельная Session → те же SQL-таблицы
```

## Ответственность компонентов

- **`Task` (`app/models.py`)** — проверяет id, название, приоритет, статус и tags; меняет состояние одной задачи. Она не читает базу.
- **`PlannerService` (`app/services.py`)** — выполняет операции Planner через переданный SQL-репозиторий и задаёт транзакционные границы записи. Он не знает о терминальном вводе и HTTP.
- **SQLAlchemy (`app/DBase/`)** — `TaskRow` описывает таблицу, `SqlTaskRepository` переводит между строкой базы и `Task`, а Session ограничивает время работы с соединением.
- **`app.core.dependencies`** — получает Session на один HTTP-запрос, создаёт для неё сервис и закрывает Session после ответа.
- **CLI (`app/cli.py`)** — распознаёт команду и показывает результат сервиса. `app.main` создаёт отдельный SQL-контекст для каждой известной команды; неизвестная команда и выход не открывают Session.
- **`app.api` и `app.main`** — загружают общие настройки базы. API и CLI используют один `DATABASE_URL`, но получают отдельные короткоживущие Session.
- **`app.DBase.import_tasks`** — отдельная одноразовая команда для проверки JSON-снимка и его транзакционного импорта в подготовленную пустую SQLite-базу. JSON не является runtime-хранилищем.

## Ошибки и ограничения

Некорректный ввод обрабатывается на границе CLI/API; неизвестная задача представлена `TaskNotFoundError`. Ошибки SQL не маскируются под пустой список и не переключают приложение на JSON или память. Схема создаётся отдельной командой, а не при обычном запуске CLI/API.

SQLite локальна; API не включает аутентификацию и production deployment. JSON-снимок можно использовать только как явный источник одноразового импорта. После импорта актуальное состояние находится в базе, поэтому старый архив не заменяет резервную копию SQLite.
