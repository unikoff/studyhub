# Краткий план защиты проекта (5 минут)

1. **Назначение и путь одной задачи (около минуты).** Добавление начинается в CLI. Команда вызывает `PlannerService`, который передаёт изменение SQL-репозиторию; CLI показывает результат.
2. **Границы ответственности (около минуты).** `Task` владеет правилами одной задачи, сервис — прикладными операциями, SQL-репозиторий — доступом к SQLite, CLI — вводом и сообщениями, `main` — сборкой зависимостей.
3. **Проверки (около минуты).** CLI и API интеграционные тесты проверяют пользовательский результат через изолированную SQLite; import rehearsal использует копию JSON в `tmp_path`.
4. **Восстановление (около минуты).** Перезапустить API и CLI и показать сохранённые id/статус из SQLite. Неизвестный id и ошибку базы проверять отдельно; повреждённый JSON относится к явной команде импорта.
5. **Компромиссы и запуск (около минуты).** README содержит команды установки, тестов и запуска. SQLite даёт транзакционное хранение; JSON используется только как источник явного импорта. Принятую версию сверять через `git rev-parse HEAD`.
